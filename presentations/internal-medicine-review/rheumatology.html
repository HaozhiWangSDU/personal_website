1.1 风湿性疾病的定义、疾病谱特征与病理活检定位

掌握
  • 定义（课本 P808）：风湿性疾病（rheumatic disease）是一组累及骨与关节及其周围软组织（如肌肉、肌腱、滑膜、滑囊、韧带和软骨等），以及其他相关组织和器官的慢性疾病。包含 10 大类 100 余种疾病，病因多样、发病机制不甚明了，但多数与自身免疫异常密切相关；既可为局限性病理损伤，也可为全身性疾病，不及时诊治多有致残甚至致死风险。
  • 疾病谱变迁：感染相关风湿性疾病已明显减少，而骨关节炎、痛风性关节炎发病率呈上升趋势；IgG4 相关性疾病、自身炎症性疾病等新病种不断被认识；分类/诊断标准由单纯“计算条目个数”发展为计算不同条目权重评分总分。
  • 病理活检的决定性意义（课本 P812 / PDF P843）：活组织检查对诊断有决定性意义并指导治疗：
    • 肾脏活检：狼疮性肾炎（LN）病理分型；
    • 滑膜活检：关节炎病因判断；
    • 唇腺活检：干燥综合征（SS）诊断；
    • 肌肉活检：多发性肌炎/皮肌炎（PM/DM）诊断。

1.2 实验室检查：常规指标、五大类自身抗体（完整表 8-1-4）、HLA 与关节液

掌握

（一）常规与炎症/免疫指标：血、尿、便常规及肝肾功能必不可少（WBC 变化、溶血性贫血、血小板减低、蛋白尿、镜下血尿均提示风湿病可能）。ESR 增快、CRP 升高提示 RA、血管炎等活动；补体 C3、C4 下降常伴随 SLE 活动。

（二）五大类自身抗体核心概念（诊断须以临床表现为基础，不可单凭抗体确诊）：

  1. 抗核抗体（ANA）：靶抗原包括核酸、组蛋白、非组蛋白及各种蛋白酶，已由传统细胞核扩大到整个细胞（含细胞质及细胞器）；分为抗 DNA、抗组蛋白、抗非组蛋白、抗核仁及抗其他细胞成分 5 大类。其中抗 ENA 抗体（可被盐水提取的可溶性抗原）对鉴别诊断尤为重要，但与疾病严重程度及活动度无关。正常老年人或肿瘤患者血清可出现低滴度 ANA。
  2. 类风湿因子（RF）：靶抗原为变性 IgG 分子的 Fc 片段。RA 阳性率约 80%，但特异性较差——亦见于 pSS、SLE、SSc 等 CTD、感染性疾病、肿瘤及约 5% 正常人群。
  3. 抗中性粒细胞胞质抗体（ANCA）：靶抗原为中性粒细胞胞质成分，主要为丝氨酸蛋白酶 3（PR3）和髓过氧化物酶（MPO），与血管炎密切相关。
  4. 抗磷脂抗体（APL）：靶抗原为各种带负电荷的磷脂；临床常测抗心磷脂抗体、抗 β₂ 糖蛋白Ⅰ抗体、狼疮抗凝物，主要致凝血改变（血栓形成、血小板减少、病理妊娠）。
  5. 抗角蛋白抗体谱：靶抗原为细胞基质中的聚角蛋白微丝蛋白，对 RA 特异度高且助早期诊断，包括 APF、AKA 及人工合成环化肽抗 CCP 抗体（较 AKA 灵敏度和特异度更好）。

（三）人类白细胞抗原（HLA）关联

  • HLA-B27：与中轴关节受累脊柱关节炎密切关联；AS 阳性率 90%，也见于反应性关节炎、银屑病关节炎；正常人群阳性率 10%。
  • 其他关联：HLA-B5 ↔ 贝赫切特病（BD）；HLA-DR2、DR3 ↔ SLE；HLA-DR3、B8 ↔ pSS；HLA-DR4 ↔ RA。

（四）关节液检查核心阈值

  • 非炎性关节炎：WBC 往往在 2000×10⁶/L 以下。
  • 炎性关节炎：WBC 超过 3000×10⁶/L，且中性粒细胞达 50% 以上。
  • 化脓性关节炎：外观呈脓性且 WBC 更高；细菌涂片/培养阳性助诊感染性关节炎。
  • 痛风性关节炎：关节液中找到尿酸盐结晶。

1.3 影像学检查：骨关节评估与肌肉骨骼外脏器评估

掌握
检查方法适用部位与核心诊断价值（课本 P812 / PDF P843）
X 线骨和关节检查最常用；发现软组织肿胀及钙化、骨质疏松、关节间隙狭窄、关节侵蚀脱位、软骨下囊性变。
关节 CT / 双能 CT检测多层组织重叠部位（骶髂关节、股骨头、胸锁关节、椎间盘），较 X 线敏感性更高；双能 CT 有助检测痛风性关节炎患处痛风结晶。
MRI对软组织、关节软骨损伤、骨髓水肿、缺血性骨坏死、早期微小骨破坏和肌肉炎症是灵敏可靠的检测手段。
关节超声早期发现关节滑膜、软骨损伤，并监测病情变化。
受累脏器影像胸部高分辨率 CT（HRCT）→肺间质病变；头颅 CT/MRI→SLE 中枢神经受累；血管超声、CTA、MRA、血管造影、PET→血管炎评价。

1.4 抗风湿四类主要药物及辅助性治疗：分类、作用机制与应用原则（含完整表 8-1-5）

掌握
  • 治疗总目标：尽早治疗，维持关节/脏器功能、缓解症状、提高生活质量、改善预后（含一般治疗、药物治疗及矫形/滑膜切除/关节置换等手术治疗）。抗风湿性疾病药物主要包括 NSAIDs、糖皮质激素、DMARDs 及生物制剂四类，另配合辅助性治疗。
  • 1. 非甾体抗炎药（NSAIDs）：机制为抑制环氧化酶（COX）→抑制花生四烯酸转化为前列腺素；抗炎解热镇痛起效快，但不能控制原发病病情进展。具消化道、肾及心血管副作用，临床应用时需要随访（老年、有消化道/肾基础病更须谨慎）；选择性 COX-2 抑制剂可减少胃肠道副作用。
  • 2. 糖皮质激素（GC）：强大抗炎+免疫抑制，为多种 CTD 一线药物。
    • 半衰期分类：短效（可的松、氢化可的松）；中效（泼尼松、泼尼松龙、甲泼尼龙、曲安西龙等）；长效（地塞米松、倍他米松等）。
    • 肝功能不全优选：氢化可的松、泼尼松龙、甲泼尼龙为 11 位羟基化合物，可不经肝脏转化直接发挥生理效应。
    • 长期大量不良反应与监测：感染、高血压、高糖血症、骨质疏松、撤药反跳、无菌性股骨头坏死、肥胖、精神兴奋、消化性溃疡等；临床应用须权衡疗效和副作用，严格掌握适应证、剂量及疗程，并监测不良反应。
  • 3. 改善病情的抗风湿药（DMARDs）：分传统 DMARDs 与靶向 DMARDs；共同特点为改善和延缓病情进展（防止/延缓 RA 骨结构破坏）；起效慢，通常治疗 2～4 个月才显效，缓解后宜长期维持。
  • 4. 生物制剂：基因工程单克隆抗体，靶向阻断关键发病环节：
    • TNF-α 靶点：率先在 RA、脊柱关节炎成功，迅速改善病情、阻止关节破坏；
    • IL-6 受体拮抗剂、阿巴西普（CTLA-4 与 IgG1 Fc 融合蛋白）：用于 RA；
    • 抗 CD20 单抗（利妥昔单抗）：获批用于 ANCA 相关血管炎一线治疗，并用于难治性 SLE（肾炎、溶血性贫血、血小板减少）；
    • 贝利尤单抗（抗 B 细胞刺激因子单抗）、泰它西普：用于标准治疗疗效不佳的 SLE；
    • 主要不良反应为感染、过敏反应，用药前必须筛查感染，尤其是乙型肝炎和结核。
  • 辅助性治疗（非上述四类抗风湿药物，作为辅助手段）：静脉输注免疫球蛋白（IVIG）、血浆置换、血浆免疫吸附。

2.1 RA 定义与基本病理特点（滑膜炎、血管翳、血管炎、类风湿结节）

掌握
  • 定义：以侵蚀性、对称性多关节炎为主要临床表现的慢性、全身性自身免疫病；发病高峰 35～50 岁，女性患病率 2～3 倍于男性；我国患病率 0.42%（平均发病年龄 47 岁）。
  • 关节基本病理——滑膜炎与血管翳（pannus）：
    • 急性期：滑膜渗出和细胞浸润；滑膜下层小血管扩张、内皮细胞肿大、细胞间隙增大、间质水肿和中性粒细胞浸润。
    • 慢性期：滑膜肥厚形成绒毛样突起，突向关节腔或侵入软骨和软骨下骨质，即血管翳（pannus）——具很强破坏性，是造成关节软骨和骨破坏的病理基础。镜下见滑膜细胞由正常 1～3 层增生至 5～10 层或更多（大部为巨噬细胞样 A 型细胞和成纤维细胞样 B 型细胞）；滑膜下层大量淋巴细胞弥漫或聚集成淋巴滤泡样（大部为 CD4⁺T 细胞，次为 B 细胞和浆细胞），伴新生血管、活化成纤维样细胞及纤维组织。
  • 关节外病理——血管炎与类风湿结节：可累及中、小动脉和/或静脉，见血管内膜增生、管壁淋巴细胞浸润、纤维素样坏死→管壁增厚、管腔狭窄或闭塞。类风湿结节是血管炎典型表现，呈三层结构：中心为纤维素样坏死组织 → 周围为环状排列的上皮样细胞浸润 → 最外层为肉芽组织。

2.2 临床表现：核心关节表现与 8 大系统关节外表现

掌握

（一）核心关节表现（多慢性起病，手、腕、足双侧对称多关节肿痛首发，可伴乏力、低热、肌痛、体重下降）：

  • 晨僵：关节僵硬和胶着感，晨起明显、活动后减轻，通常持续超过半小时；为判断疾病活动指标之一（主观性强），RA 最突出。
  • 关节痛与压痛：往往是 RA 最早的症状，多呈对称性、持续性，部位与肿胀一致。
  • 关节肿胀：滑膜增生、关节腔积液及周围软组织水肿所致，多对称；最常累及腕、掌指（MCP）、近端指间（PIP）关节，其次为足趾、膝、踝、肘、肩关节。
  • 关节畸形（较晚期）：肌萎缩与痉挛加重畸形；最常见为掌指关节半脱位、手指向尺侧偏斜、“天鹅颈（swan neck）”样畸形、“纽扣花（boutonniere）”样畸形，腕和肘关节强直亦较常见。

（二）关节外表现（8 大系统完整梳理）：

受累系统特征性临床表现与重要数值（课本 P815–816）
1. 皮肤类风湿结节最常见的关节外表现（见于 30%～40% 患者）；多见于活动期、男性、长期大量吸烟者；好发关节隆突及受压处（前臂伸面、尺骨鹰嘴下方、跟腱、滑囊）；质硬、无压痛、对称分布；存在提示 RA 病情活动。
2. 皮肤血管炎发生率 <10%，见于长病程、RF 阳性且活动者；表现为瘀点、紫癜、指/趾坏疽、梗死、网状青斑、皮肤深大溃疡；须积极用免疫抑制剂。
3. 心脏心包炎最常见（多见于 RF 阳性、有结节者）；<10% 有临床症状，近半数可经超声心动图检出。
4. 肺（男>女，可首发）① 肺间质病变（ILD）：最常见肺病变（约 30%），活动后气短、肺纤维化，肺功能+肺部 HRCT 助早诊；② 胸膜炎（约 10%，单/双侧少量渗出性积液）；③ 肺结节（可液化空洞；尘肺合并 RA 出现大量大结节称 Caplan 综合征/类风湿性尘肺病）。
5. 眼与继发干燥综合征最常见为继发干燥综合征所致干眼症（可能合并口干、淋巴结肿大，须结合自身抗体及口腔科、眼科检查进一步明确诊断）；另可出现巩膜炎（重者溃疡、穿孔致视力损害，病理为巩膜血管炎，常提示活动）。
6. 神经系统神经受压最常见（腕关节正中神经受压→腕管综合征）；继发血管炎致手足麻木或多发性单神经炎（提示活动）；C₁～C₂ 颈椎受累→脊髓病变。
7. 血液系统贫血最常见（程度与关节炎症相关，控制后改善）；活动期血小板增多。Felty 综合征 = RA + 脾大 + 中性粒细胞减少（可伴贫血/血小板减少、下肢溃疡、结节、发热等突出关节外表现）。
8. 肾少见（偶有轻微膜性肾病、肾小球肾炎、肾内小血管炎、肾淀粉样变）；出现肾损须警惕长期服 NSAIDs 药物所致。

2.3 类风湿因子（RF）与抗瓜氨酸化蛋白抗体（ACPA / 抗 CCP）

掌握

类风湿因子（RF）

  • 定义：针对 IgG Fc 片段抗原表位的自身抗体，分 IgM、IgG、IgA 型，常规测 IgM 型 RF。
  • 临床意义：RA 阳性率 75%～80%；但非 RA 特异性抗体（慢性感染、其他自免病及 1%～5% 健康人可阳性）；RF 阴性不能排除 RA。

抗瓜氨酸化蛋白抗体（ACPA）

  • 组成：抗 CCP、抗 MCV、APF、AKA、AFA。
  • 抗 CCP 临床意义：RA 阳性率约 75%，特异度极高（93%～98%），可在疾病早期出现且与预后相关。
  • 血清学阴性 RA：约 15% 患者 RF 和 ACPA 均为阴性。

2.5 治疗原则（早期、达标、个体化）与六类抗 RA 药物使用原则

掌握

总原则：RA 不能根治，遵循早期、达标（T2T）、个体化原则；主要目标是达到临床缓解或低疾病活动度，最终目的是减少致残。药物治疗最重要，初始治疗必须应用一种 DMARDs。

药物类别代表药物与定位使用原则与核心不良反应（课本 P818–819）
1. NSAIDs缓解关节炎症状常用药镇痛抗炎但控病情有限，须与 DMARDs 同服；可增心血管事件；避免 2 种或以上 NSAIDs 同服。
2. 传统 DMARDs首选甲氨蝶呤（MTX）；余 LEF、SASP、HCQ起效慢（1～3 个月），无明显镇痛抗炎但可延缓控制进展；确诊即尽早启用，可单用或 ≥2 种联用。
3. 生物 DMARDs最普遍：TNF-α 抑制剂、IL-6 拮抗剂；另 IL-1i、CD20 单抗、CTLA-4 融合蛋白传统 DMARDs 未达标或有预后不良因素时加用；宜与 MTX 联用增效减副；TNF-α 抑制剂可增加特殊感染复燃风险，用前应筛查结核和肝炎病毒感染；有些生物制剂长期使用可能增加肿瘤风险，用药前应除外肿瘤；副作用含注射/输液反应及感染（呼吸道/带状疱疹）。
4. 靶向 DMARDsJAK 抑制剂：托法替布、巴瑞替尼、乌帕替尼起效快，传统 DMARDs 反应不足时联用；副作用：WBC 减少、肝损、感染（肝炎/结核/疱疹）、增加心血管及血栓事件风险（高危者慎用）。
5. 糖皮质激素（GC）“桥梁治疗（bridge therapy）”原则：小剂量、短疗程，必联 DMARDs，待 DMARDs 起效后减停；严重关节外受累（心肺眼神经、继发血管炎）予中到大剂量；关节腔注射 1 年内不宜超过 3 次（防感染/类固醇晶体性关节炎）；均应补钙 + VitD 防骨松。
6. 传统中药/植物药最常用：雷公藤多苷；另白芍总苷、青藤碱缓解关节症状较好，长期控病情待证实；注意性腺抑制、胃肠道不适、肝损和骨髓抑制。

2.6 病因发病机制、特殊关节、ACR 功能分级与辅检/影像分期

熟悉

病因与发病机制

  • 遗传：一级亲属患 RA 概率 11%；HLA-DRB1 等位基因突变相关。
  • 环境：病原体激活 T/B 细胞或分子模拟；吸烟显著增加 RA 风险。
  • 免疫紊乱：活化 CD4⁺T 与 MHC Ⅱ⁺ APC 浸润滑膜；B 细胞、巨噬细胞、滑膜成纤维细胞协同致炎。

特殊关节与 ACR 功能 4 级

  • 肩/髋：周围软组织多不易见肿，髋痛常位于臀部及下腰部；颞下颌：讲话咀嚼痛、张口受限；颈椎：最重为 C₁～C₂ 寰枢关节半脱位压迫脊髓。
  • ACR 功能分级：Ⅰ 照常生活工作；Ⅱ 一般生活+某种工作，其他活动受限；Ⅲ 一般生活，工作及其他活动受限；Ⅳ 自理与工作均受限。
  • 血液与炎症指标：轻中度正细胞正色素性贫血；活动期血小板增多，WBC 多正常；Ig 升高，补体多正常或轻升；ESR、CRP 反映活动度。
  • 关节滑液：正常 ≤3～5ml；RA 呈淡黄、透明、黏稠，WBC 5000～50000×10⁶/L（约 2/3 多核）；证实炎症并鉴别感染/痛风/假性痛风，不能确诊 RA。
  • 双手/腕 X 线 Ⅰ–Ⅳ 期：Ⅰ 期 软组织肿胀 + 关节附近骨质疏松 → Ⅱ 期 关节间隙变窄 → Ⅲ 期 关节面虫蚀样改变 → Ⅳ 期 半脱位与纤维性/骨性强直。
  • MRI / 超声 / 活检：MRI 对早期诊断极有意义，可显示关节软组织病变、滑膜炎症/水肿/增生、关节积液及骨髓水肿等，较 X 线更敏感；高频超声显示滑膜增生并通过血流信号反映炎症活动度及引导穿刺；关节镜及针刺活检具辅助价值。

2.7 病情判断（DAS28）、一般/外科治疗与预后

熟悉
  • 病情判断：综合评估晨僵时间、压痛/肿胀关节数、ESR/CRP 及医患评分，临床常用 28 关节评估工具 DAS28；并评估影响预后因素（病程、躯体功能 HAQ 评分、关节外表现、自身抗体阳性、早期 X 线骨破坏）。

3.1 SLE 定义与多系统临床表现（13 大系统完整版）

掌握

定义与流病：SLE 是以致病性自身抗体和免疫复合物形成并介导器官、组织损伤的自身免疫病，临床多系统受累，血清存在以 ANA 为代表的多种自身抗体。我国患病率（30.13～70.41）/10 万，好发于 20～40 岁育龄女性，黄种人发病率位居全球第二。

受累系统核心临床表现、特征体征与关键数值（课本 P821–822）
1. 全身表现活动期多发热（以低、中度热常见），伴疲倦、乏力、食欲缺乏、肌痛、体重下降。
2. 皮肤与黏膜80% 出现皮疹，以鼻梁和双颧颊部蝶形红斑最具特征性（皮疹多无明显瘙痒）；另见盘状红斑、指掌/甲周红斑、指端缺血；口腔及鼻黏膜无痛性溃疡和脱发（弥漫或斑秃）常提示疾病活动。
3. 浆膜炎半数以上急性发作期出现多发性浆膜炎（双侧中小量胸腔积液、中小量心包积液）；评估活动度时须与 LN 肾综低蛋白血症、心肌病或重度 PAH 所致积液甄别。
4. 肌肉关节指、腕、膝对称性多关节痛/肿痛，伴红肿少见。10% 出现 Jaccoud 关节病（肌腱受损所致可复的非侵蚀性关节半脱位，X 线多无骨破坏）；5%～10% 肌炎；小部分患者病程中出现股骨头坏死，但原文指出尚不能肯定系 SLE 本身还是糖皮质激素不良反应所致。
5. 肾脏表现27.9%～70% 病程受累（中国首发仅 25.8%）；蛋白尿、血尿、管型尿、水肿、高血压乃至肾衰；平滑肌受累可致输尿管扩张与肾积水。（LN 病理分型原文指向第五篇，本章未设专节。）
6. 心血管心包炎（心脏压塞少见）；疣状心内膜炎（Libman-Sacks 心内膜炎）：常见于二尖瓣后叶心室侧，不改变心脏杂音性质，可脱落栓塞或并发 IE；约 10% 心肌损害；冠脉受累（冠脉炎 + aPL 血栓 + 长期激素致动脉粥样硬化）。
7. 肺部表现ILD（急/亚急性磨玻璃影 + 慢性纤维化，弥散下降）；约 2% 合并弥漫性肺泡出血（DAH），凶险、病死率高达 50% 以上（BALF 呈血性或见大量含铁血黄素巨噬细胞助诊）；肺动脉高压（PAH）预后不良（超声+右心漂浮导管诊断）。
8. 神经系统（NPLE）又称狼疮脑病，中枢（癫痫、狼疮性头痛、脑血管病、无菌性脑膜炎、脱髓鞘、运动障碍、脊髓病、意识错乱、精神病等）与周围（GBS、自主/单/多发神经病、重症肌无力等）均可累及；病理基础为脑局部血管炎微血栓、Libman-Sacks 小栓子、抗神经细胞抗体或并存 APS；CSF 压力及蛋白↑（细胞/氯/糖多正常）+ MRI 助诊。
9. 消化系统食欲减退、腹痛、呕吐、腹泻；早期肝损预后不良；少数急腹症（胰腺炎、肠坏死、肠梗阻）与活动相关，机制为肠壁及肠系膜血管炎；失蛋白肠病/肝病早期用激素多快改善。
10. 血液系统活动期 Hb↓、WBC↓、PLT↓；10% 为 Coombs 阳性溶血性贫血；PLT↓与抗血小板抗体、aPL 及骨髓巨核细胞成熟障碍相关；部分无痛性淋巴结肿大、少数脾大。
11. 合并 APS近 1/3 SLE 合并 aPL 阳性，少部分可诊 APS：临床表现可包括动脉和/或静脉血栓形成、病理妊娠、血小板减少等，伴持续抗磷脂抗体阳性；SLE 患者血清可出现抗磷脂抗体，但临床表现不一定符合 APS 诊断（第十二章未入大纲，仅按本章界定）。
12. 干燥综合征约 30% 患者并存继发性干燥综合征。
13. 眼部表现约 15% 眼底病变（视网膜出血、渗出、视盘水肿，系视网膜血管炎），累及视神经重者可数日致盲，早期治疗多数可逆。

3.4 个体化治疗策略：一般治疗、激素、羟氯喹、免疫抑制剂（表 8-3-3）与生物制剂

掌握
  • 总原则：不能根治，须个体化；糖皮质激素联合免疫抑制剂为主；两阶段：急性期积极诱导缓解 → 缓解后维持缓解（保脏器、减副反应），同时防治伴发疾病（动脉粥样硬化、高血压、血脂异常、糖尿病、骨质疏松）及强化宣教随访。
  • 一般治疗 6 要点：① 心理治疗树立乐观；② 急性活动期卧床，稳定慢性期适当工作勿过劳；③ 早发现早治感染；④ 避免诱发狼疮药物（如避孕药）；⑤ 避免强阳光暴晒和紫外线照射；⑥ 缓解期才可防疫注射且尽可能不用活疫苗。对症治疗：NSAIDs 退热/止关节痛、控制代谢合并症、NPLE 予降颅压/抗癫痫/抗抑郁。
  • 1. 糖皮质激素：
    • 诱导缓解：泼尼松 0.5～1 mg/(kg·d)，病情稳定 2 周或 6 周后逐渐减量；
    • 长期维持：病情允许时泼尼松 <10 mg/d 小剂量维持；
    • 狼疮危象激素冲击：甲泼尼龙 500～1000 mg 静滴 qd×3～5 天为 1 疗程，必要时 1～2 周后可重复。
  • 2. 羟氯喹（基础治疗）：SLE 患者如无禁忌均建议服用，可降疾病活动度、降器官损伤和血栓风险、改善血脂、提高生存率。眼科风险评估：高风险每年 1 次眼科检查，低风险服药第 5 年起每年 1 次。
  • 3. 免疫抑制剂：活动时联用可更好控活动、保脏器、减复发、减激素用量；重要脏器受累诱导缓解期首选 CTX 或 MMF，无明显副作用建议至少用 6 个月；维持期选 1～2 种长期维持。
  • 4. 生物制剂与其他治疗：激素/免疫抑制剂疗效不佳、不耐受或复发者考虑生物制剂——我国已获批适应证：贝利尤单抗、泰它西普；利妥昔单抗虽未获批适应证，但指南提及对部分顽固性 LN 及血液受累有效。危重/困难病例可选 IVIG、血浆置换。（注：第 10 版第三章未提及“干细胞移植”。）

3.5 病因、免疫发病机制与特征性病理改变

熟悉

病因三要素

  • 遗传：第 1 代亲属中患 SLE 者为无 SLE 家庭的 8 倍，单卵双胞胎患 SLE 者为异卵双胞胎的 5～10 倍；多基因叠加（HLA Ⅲ 类 C2/C4 缺失、HLA Ⅱ 类 DR2/DR3 异常），已发现的 SLE 相关基因仅能解释约 15% 的遗传可能性。

  • 基本改变：全身任何器官炎症反应与中小血管异常（IC 沉积或抗体侵袭致管壁炎/坏死 + 继发血栓缺血）。

4.3 第三节 巨细胞动脉炎（GCA，大纲重点理解）

掌握
  • 定义、流病与病因：又称颞动脉炎，老年人慢性肉芽肿性全层动脉炎，常累及主动脉弓及其一级分支尤其颞动脉。50 岁以上发病（高峰 74 岁），女∶男 2～4∶1，北欧最高亚洲最低；病因不清，与遗传因素（HLA-DRB1*01/*04 单倍体型）、高龄、血管退行性变及吸烟、病毒感染等有关（注：本节列病因相关因素及病理，未设独立发病机制专节）；病理与 TA 几乎相同（全层炎细胞浸润、内膜增生、内弹性膜断裂、巨细胞肉芽肿）。
  • 临床表现：隐袭起病伴全身症状；70% 出现一侧或双侧颞部头痛、头皮触痛、颞下颌关节间歇性运动障碍，颞浅动脉增粗变硬呈结节状伴压痛；30% 头颈动脉缺血（视力下降、复视、眼肌麻痹甚至失明，听力减退、眩晕）；15% 主动脉弓分支缺血（上肢跛行、脉弱/无脉、双上肢压不等）；40%～60% 伴风湿性多肌痛（PMR）（颈、肩胛带、骨盆带酸痛晨僵，肌压痛及肌力减弱不显著）。
  • 实验室与诊断：最突出异常为 ESR 明显增快（平均 >50 mm/h）、CRP 升高，常伴贫血及 WBC/PLT↑。50 岁以上新发颞部头痛 + 颞浅动脉搏动减弱/增粗变硬 + 颞动脉活检见肉芽肿性动脉炎可确诊（因节段性易假阴性，颞动脉造影/CTA/MR/PET 助诊）。
  • 治疗与预后：对糖皮质激素反应十分明显——泼尼松（龙）40～60 mg/d（1 周内症状消失，减量易复发须小剂量长期维持）；复发加 MTX、AZA、CTX；出现视力改变尤其急剧下降者须考虑甲泼尼龙 500～1000 mg/d 冲击治疗 3 天；IL-6 单抗疗效好且减激素，已成为 GCA 的一线治疗药物。大多预后良好。

掌握
  • 定义、病因机制与病理：以血清 ANCA 阳性为最突出特点的系统性小血管炎（小动脉/微小动脉/微小静脉/毛细血管，偶累中动脉），包括 MPA、GPA、EGPA。病因和发病机制：遗传因素、感染（尤其是细菌感染）与发病关系密切；除 ANCA 参与发病外，感染对血管壁的直接损害起重要作用；受累脏器仅有极少量或无免疫复合物沉积。病理为小血管全层炎症、坏死（纤维素样坏死+中性粒/淋巴/嗜酸性细胞浸润），伴或不伴肉芽肿，是确诊“金标准”。

4.5 系统性血管炎总论病因与发病机制细节

熟悉
  • 遗传与感染/药物病因：HLA-DRB1*01/*04 → GCA；HLA-DRB52*01 → TA；HLA-DP/HLA-DQ → AAV。感染：病毒（概论述 10% PAN 伴 HBV，第四节进一步指出随着乙肝疫苗普及已降至 5% 以下；80% 混合型冷球蛋白血症伴 HCV）、结核分枝杆菌（TA、白塞病）；药物诱导 ANCA 血管炎：丙硫氧嘧啶、肼屈嗪、可卡因。
  • 四大机制：① 外来感染原直接损伤血管；② 巨噬细胞活化释放 TNF-α、IL-6、IL-1；③ 自身抗体 ANCA（主要靶抗原 PR3、MPO，另含弹性蛋白酶、乳铁蛋白）；④ 补体旁路途径激活释放 C5a 造成血管和脏器损伤。

4.6 第四节 结节性多动脉炎（PAN）

熟悉
  • 定义、病因与病理：累及中、小动脉的局灶性全层坏死性血管炎，好发于血管分叉处；男>女，高峰 40～50 岁。病因不明，与遗传因素和病毒感染相互作用相关，既往发现 HBV、HCV、HIV 感染有关，随着乙肝疫苗普及，HBV 相关 PAN 现仅占 5% 以下。很少累及肺动脉，急性期纤维素样坏死、管壁破坏形成动脉瘤及血栓。
  • 临床表现（系统性[特发/HBV相关] vs 皮肤型）：
    • 系统性 PAN：全身症状 90%；① 神经系统最常受累（36%～72%）：多发性单神经炎（垂腕、垂足、麻木）；② 肾（30%～60%）：入球血管受累致肾多发梗死、高血压、SCr↑、血尿蛋白尿，但肾小球本身几乎不受累；③ 消化（近 40%）：腹痛/出血/肠梗死穿孔；④ 生殖：20% 睾丸痛/硬结（尸检 80%）；⑤ 眼、肢体坏疽、心衰/心梗。
    • 皮肤型 PAN（罕见）：40 岁以上女性常见，下肢皮肤溃疡、网状青斑、皮下结节、白色萎缩、紫癜，易复发。
  • 检查与 1990 年 ACR 分类标准（10 项满足 ≥3 项分类为 PAN）：ANCA 阴性；血管造影见内脏/下肢中小动脉节段性扩张和狭窄呈“念珠样”改变（具诊断特异性）；活检确诊。10 项指标（须除外其他 CTD 并发血管炎及 AAV）：① 体重下降（病初即有，无节食或其他因素）；② 网状青斑（四肢或躯干呈斑点及网状斑）；③ 睾丸痛或触痛（非感染、外伤或其他因素所致）；④ 肌痛、无力或下肢触痛（弥漫性肌痛[不包括肩部、骨盆带肌]或肌无力，或小腿肌肉压痛）；⑤ 单神经炎、多发性单神经炎或多神经炎；⑥ 舒张压 ≥90mmHg 的高血压；⑦ BUN ≥14.3mmol/L 或 SCr ≥133μmol/L（非脱水或阻塞所致）；⑧ 乙肝病毒（HBsAg 或 HBsAb 阳性）；⑨ 动脉造影异常（内脏动脉闭塞或动脉瘤，除外其他原因引起）；⑩ 中小动脉活检（血管壁有中性粒细胞，或中性粒细胞、单核细胞浸润）。
  • 治疗与预后：65 岁以下且无神经/肾/心损害的特发性系统性 PAN 单用 GC 即可；有上述脏器损害予泼尼松 1mg/(kg·d) + 免疫抑制剂（首选 CTX），缓解后 AZA/MTX 维持。HBV 相关 PAN 须抗病毒（6～12 个月）联合 GC（控制不佳加免疫抑制）。未治 5 年生存率 <15%，积极合理治疗可达 83%。

4.7 第六节 贝赫切特病（BD / 白塞综合征）

熟悉
  • 定义、病因与独特病理：又称白塞病，现统一称白塞综合征；以口腔溃疡、外阴溃疡、眼炎为特征，依内脏受损分血管型、神经型、胃肠型；中国北方发病率 110/10 万，男略多于女。病因尚不清楚，可能与遗传因素及感染有关。独特之处：大、中、小及微血管及动、静脉均可受累（炎症、增厚狭窄、坏死、动脉瘤、继发血栓）。
  • 基本症状（4 项）与系统性症状（6 项）：
    • 口腔溃疡：98% 以上患者、首发且最基本必需症状；每年发作 ≥3 次，痛性、2～3mm、7～14 天自愈多不留瘢痕；
    • 外阴溃疡：约 80%，性状似口腔溃疡；
    • 皮肤病变：结节性红斑最常见（70%，膝下对称浸润痛性结节，很少破溃）、毛囊炎（30%，面颈多见）、针刺反应、下肢浅表血栓性静脉炎；
    • 眼炎：葡萄膜炎及视网膜血管炎（反复致盲；前葡萄膜炎可伴前房积脓）；
    • 内脏系统：① 消化道（肠白塞，多发溃疡发生率高达 50%，右下腹痛最常见，可穿孔/出血/瘘管致死）；② 神经白塞（20%，急骤起病，含中枢实质损害及中枢静脉血栓）；③ 血管白塞（10%，动脉狭窄与动脉瘤交替；大静脉上/下腔静脉梗阻，四肢/脑静脉血栓；心脏少见）；④ 关节炎（30%～50%，膝最多见、一过性自限）；⑤ 肺小动脉瘤（大咯血致命）及肺栓塞；⑥ 附睾炎。
  • 检查、针刺反应与 2014 国际诊断标准（表 8-6-3）：无特异血清抗体（ANA 谱、ANCA、aPL、补体均正常）。针刺反应是目前唯一特异性较强的试验：无菌针刺入前臂屈面皮内退出，48 小时后局部出现红丘疹或伴白疱疹为阳性。2014 国际标准总分 ≥4 分（原文“4 分以上”）诊断：

    眼病 / 生殖器阿弗他溃疡 / 口腔阿弗他溃疡各 2 分口腔：每年至少 3 次肯定溃疡；眼病：前/后葡萄膜炎、视网膜血管炎、玻璃体细胞

  • 治疗与预后：
    • 对症治疗：局部激素软膏/眼药；秋水仙碱为防止皮肤黏膜病变（尤其结节性红斑和生殖器溃疡）复发的首选药；沙利度胺（25～100mg/d）治口腔溃疡效佳，可致“海豹胎”畸形、孕妇禁服。
    • 脏器与眼炎治疗：后葡萄膜炎→GC + AZA / CsA / IFN-α / TNF-αi；急性 DVT→GC + AZA / CTX / CsA；胃肠道→GC + AZA / TNF-αi；中枢神经→大剂量 GC + AZA / TNF-αi。
    • 手术与预后：动脉瘤介入/切除，肠穿孔/大出血/梗阻急诊手术。大多预后良好，眼病可致盲，胃肠严重并发症与感染是高死亡主因。
